## 现状盘点（0.26.0）

面板已经解决的：一行说一件事、事实不重复、Recent 折叠、标题不截断、图标齐全。

**剩下的问题不在「怎么显示」，在「显示完之后你能做什么」。**

Pulse 的职责是「有事叫你」。但用户对一次 Waiting 只有两种回应：

1. 现在就去处理（点行 → 聚焦终端）
2. 「清除等待」—— 永久抹掉

中间那个最常见的回应不存在：**「知道了，等会儿再说」**。
现在只能靠自己记住，而「靠自己记住」正是 Pulse 存在的理由。

这是这一版的重点。

## P0 · 产品功能补齐

### P0-1 稍后提醒（Snooze）

**缺口**：`StatusStore` 有 `dismissWaiting`（抹掉）和 `clearWaiting`（全抹），
没有任何「推迟」。

**做法**：

- 行内动作加「稍后」，默认 10 分钟
- 期间：**不发通知、菜单栏不为它变红**
- 但**行照常留在列表里**，芯片改成 `已稍后 · 剩 7 分钟`

最后一条是硬要求。`EXPERIENCE.md` 已经写过「静音的 Agent 不发通知，
但照常出现在列表里」——稍后是同一个原则：**压制的是打扰，不是事实**。
一个能让行消失的按钮会让人不敢按。

**不变量检查**：Snooze 只动 Pulse 自己的提醒，不向 agent 发任何东西，
不构成「托盘内批准 / 拒绝」。✅

**验收**：
- 稍后 10 分钟内不发通知；到期自动恢复，恢复算一次「新 Waiting」边沿
- 行始终可见，剩余时间随扫描更新
- 该 Waiting 自己结束了（用户在终端里处理了），稍后状态一并清掉，不留幽灵

### P0-2 通知上的动作按钮

**缺口**：`PulseNotify` 全文没有 `UNNotificationCategory`。
横幅只能整体点击（→ 聚焦），没有按钮。

**做法**：注册一个 category，两个动作：**聚焦** / **稍后**。

这是 `EXPERIENCE.md` 那句「只说『需要你处理』而不说要什么，
用户仍得切过去才知道 —— 不算闭环」的下一步：
横幅弹出来的时候你的手正在别处，能在横幅上直接稍后才算闭环。

**验收**：两个按钮都在，中文英文都对；点「聚焦」与点横幅本体行为一致。

### P0-3 停滞阈值可配

**缺口**：`AgentRow.stalledSeconds = 20 * 60`，写死。

跑长编译的人 20 分钟不算停滞；跑短问答的人 5 分钟就该被提醒。
一个所有人都不合适的默认值。

**做法**：设置 → 通用，给 5 / 10 / 20 / 30 分钟 / 关闭。默认保持 20。

**验收**：改了立即生效（下一次扫描），关闭后 `isStalled` 恒 false，芯片消失。

## P1 · 信息传递效率

### P1-1 按项目分组也能折叠

**缺口**：`TrayFold.foldable` 第一个条件就是 `section == .recent`。
按项目分组时**任何组都不折**，项目一多就是一条长列表——
而按项目分组恰好是给「同时开好几个仓库」的人准备的。

**做法**：不含 waiting 的项目组可折叠，规则与 Recent 一致
（唯一分组不折、单行不折）。含 waiting 的组永不折叠。

**验收**：三个项目其中一个有 Waiting → 那个组展开，另两个折起；
折叠表头带 Agent 名。

### P1-2 键盘导航

**缺口**：面板里唯一的键盘支持是动作栏的 `⌘R / ⌘J / ⌘, / ⌘Q`
（`TrayIconAction` 的 `keyboardShortcut`）。行本身不可聚焦。

**做法**：↑ / ↓ 选行，Enter = 聚焦该行，Esc 关闭面板，Space 展开/折叠当前组。

**坦白**：主路径（唤面板 → 处理最急的）已经被 `⌘J` 覆盖了，
所以这条的边际收益中等。它值得做是因为**快捷键唤出的面板用鼠标收尾很别扭**——
手已经在键盘上了。

**验收**：全键盘完成「唤出 → 选中第二行 → 聚焦」；焦点环可见。

## P2 · 优雅与精致

### P2-1 行高亮改成内缩圆角（需截图确认程度，但改动本身无风险）

**现状**：`.background(hovering ? Color.primary.opacity(0.045) : Color.clear)`
加在整个 `VStack` 上——**全宽、直角、贴边**。

macOS 原生列表（邮件、访达侧栏、通知中心）的悬停/选中都是**内缩圆角矩形**。
全宽直角色块是 web 的做法，在菜单栏面板里是最容易读出「非原生」的一处。

**做法**：左右各内缩 6pt，圆角 6，`Color.primary.opacity(0.05)`。

### P2-2 折叠、行增删加过渡

**现状**：`PulseApp.swift` 里 `withAnimation` 只出现两次，都在菜单栏图标的
闪烁里。折叠是硬切，行的出现/消失也是硬切。

一个会在 2 秒节奏下自己更新的面板，行凭空跳出来是**认知负担**：
你不知道刚才那一下是新东西还是重排。

**做法**：折叠 `.easeOut(0.16)`，行增删 `.opacity + .move(.top)`。
不加弹跳、不加缩放——这是菜单栏工具，不是启动动画。

### P2-3 分组表头的材质 —— **需截图**

`SectionHeader` 用 `.background(.thickMaterial)` 做 pinned 表头。
在只有两组、面板又不长的时候，两条材质带可能比它们分隔的内容还重。

不看截图不动。可能的方向：滚动到顶时无材质，滚动后才浮现。

## 不做（这一版明确排除）

- **托盘内批准 / 拒绝** —— 不变量，Snooze 不是它的替身
- **每个项目单独静音** —— 想过，但和 Snooze 功能重叠，先看 Snooze 够不够用
- **会话历史 / 统计** —— 非目标里的「统计大盘」
- **第二个全局快捷键** —— 现在的选择器已经够，加一个只是多一处要维护的冲突检测
- **面板内搜索** —— 行数被 `maxVisibleRows` 管着，搜索是在解决一个还不存在的问题
