# 验收场景

> [`EXPERIENCE.md`](../EXPERIENCE.md) 只写现行行为规格；这里是每个场景的期望，以及**哪些测试钉住它**。
> 「证明」一栏列出的是测试套件（类型名，括号里是方法名；测试按组件分文件，见
> `PulseBar/Tests/PulseBarTests/`），由 `scripts/scenario_map.py`（`gates.sh` 的一环）核对套件与方法都存在；
> 写着「人工 / QA 脚本」的场景没有自动测试，靠 `scripts/qa_captures.sh`（跑 `PulseQA`）与真机检查 —— 这是覆盖缺口，不是免检。

71 / 83 个场景有具名测试。随功能删除的场景不再列出，编号不复用。下文里的「详情页」指托盘里一行的详情：托盘行是一行主行（灯形、Agent、项目、任务、时间），只有需要你、停滞与带上一步的运行中行多一行，BL–BX 所写的取值规则在详情页里不变。
